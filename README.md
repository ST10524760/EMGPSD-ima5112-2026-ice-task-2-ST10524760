Project Overview
The History Flashcard app is a mobile application developed as part of an Ice Task in the Introduction to Mobile Application and Web Development subject. This application was created using Kotlin and Android Studio. History Flashcard App is an interactive and entertaining app with its primary purpose being to educate users on history facts. The app presents users with a variety of Facts. The app challenges them to decide whether it's true or false.

The app was developed to meet the requirements of the assignment, which includes creating a functional mobile app and utilizing GitHub for version control and CI/CD automation using GitHub Actions.

Purpose and Features
Purpose:
The main goal of this app is to combine learning with entertainment. Users sharpen their critical thinking skills while expanding their knowledge of Facts.

Key Features:
Feature 1: Simple True/False quiz format to keep users engaged.
Feature 2: Instant feedback after each choice to confirm whether the fact is valid or a myth.
These features aim to provide a fun and educational way to discover facts while avoiding misleading ones.

Design Considerations
The design of the History Flashcard app was based on the following key considerations:

User Experience (UX): The app was designed to provide an intuitive and easy-to-navigate user interface, ensuring a seamless user experience.

Responsiveness: The app was built to ensure it performs well on different screen sizes, with particular attention to device compatibility.

Simplicity: The design is minimalistic, focusing on core features whilst implementing a cute design, without overwhelming the user.

Performance: Code optimization was considered to ensure fast response times and low battery usage.

GitHub and GitHub Actions
This project was managed using GitHub for version control, where all code changes were committed and pushed regularly. GitHub enabled collaborative coding, allowing me to keep track of changes and maintain project integrity.

GitHub Actions:
I utilized GitHub Actions to automate the build and deployment process. This includes:

Running automated tests to ensure the app's functionality.
Compiling the app into APK and AAB files, which are the formats required for distribution.
Uploading these build artifacts to GitHub for easy access.
The workflow ensures that my project is automatically built and tested every time I push changes, and it simplifies the process of delivering the final APK/AAB files for submission.
